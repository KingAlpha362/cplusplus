# C++ Fundamentals Collection

Independent console exercises covering arithmetic, menus, loops, functions, and simple user input.

## ✨ Highlights

- Start with `area.cpp` for rectangle area and perimeter.
- Explore `basic.cpp` for a menu-driven calculator and day selection.
- Additional exercises include patterns, fines, and canteen-related programs.

## 🚀 Getting started

With a C++ compiler installed, compile one exercise at a time:

```sh
g++ -std=c++17 "area.cpp" -o exercise
./exercise
```

On Windows PowerShell, use `-o exercise.exe` and run `.\exercise.exe`. Each exercise is separate; do not link every source file into one executable.
